05｜实践应用与复习卡

这一页用于复习和实际决策。目标：看到一句“很有道理”的话时，不立刻赞同，也不立刻反驳，而是先拆变量。

A. 30 秒判断法

  1. 它真正说的是哪个变量？
  2. 还有哪些变量被删掉了？
  3. 有没有反例？
  4. 它适用于什么条件，不适用于什么条件？
  5. 什么证据能让我更新现在的判断？

B. 教育 / 亲子

错误模式：我知道什么对你好 → 我替你安排 → 我替你解决 → 你越来越不会自己判断。

更好的模式 = 提供安全边界 + 提供资源 + 要求自己行动 + 允许可承受失败 + 共同复盘
  • 孩子是否自己做过选择？
  • 失败后是马上替他收拾，还是先让他解释原因？
  • 我是在降低无意义摩擦，还是把学习过程本身也拿走？

C. 公司管理

不要把“善良”写进流程，要把边界写进流程。

  • 岗位目标是什么？多久验证一次？
  • 哪些是培训问题，哪些是能力匹配问题？
  • 失败后的处理规则是否事先明确？
  • 特殊照顾是否会破坏其他人的公平预期？
  • 老板的个人感情是否正在覆盖组织反馈？

D. 投资与交易

特别警惕：“我上次就是这么赚的”“某高手一直这么做”“这个形态以前都涨”“有人靠这个赚了百万”。

统一改写：这是一个待检验假设，不是规律。

然后检查：样本量、基准、胜率、赔率、回撤、尾部损失、时间窗口、幸存者偏差。

E. 人际帮助

  1. 对方是否明确表达需求？
  2. 对方愿意投入什么？
  3. 责任边界在哪里？
  4. 如果结果不好，双方如何解释和承担？

如果这四件事都不清楚，越热心越容易产生错位期待。

F. 自我成长

  • 本周我有哪些判断被事实推翻？
  • 哪个旧经验仍在支配我？
  • 有没有我只寻找支持证据的观点？
  • 哪件失败我过度外归因？
  • 哪件失败我又过度内归因？
  • 下周我准备设计什么小实验验证它？

G. 复习卡片

卡片 1｜经验主义最大的危险是什么？

不是“使用经验”，而是把有限经验固化成不可修改的普遍规律。

卡片 2｜为什么“免费 → 不珍惜”不严谨？

因为免费只是一个变量 / 代理变量。动机、筛选、能力、机会成本、责任机制、项目质量都可能影响结果。

卡片 3｜主体性的最小定义？

能够自己形成判断、采取行动、承担后果，并依据反馈更新模型。

卡片 4｜制度的作用是什么？

不是消灭主体性，而是处理信息不对称、权责冲突和自我约束不足，让反馈稳定存在。

卡片 5｜孔子“不愤不启”最重要的现代解释？

学习者必须主动加工信息；教师提供启发，而不是替代思考。

卡片 6｜守株待兔对应什么逻辑错误？

把一次偶然样本过拟合成稳定因果规则。

卡片 7｜郑人买履对应什么错误？

让代理模型压过现实反馈。

卡片 8｜休谟提醒什么？

过去重复发生不能仅凭逻辑保证未来必然继续发生。

卡片 9｜波普尔式问题是什么？

不要只问“什么证明我对”，而要问“什么出现我就承认自己错”。

卡片 10｜最终原则？

格言用来生成假设，现实反馈用来修改假设。

H. 一句话索引

主体性 → 判断权不外包内驱力 → 行动为什么发生自主性 → 行动是否出于自我认可责任 → 谁选择，谁承担反馈 → 现实是否有资格否定我元认知 → 我能否观察自己的判断过程经验主义 → 经验被固化成普遍规则启发式 → 低成本但有边界的快速判断制度 → 稳定权责和反馈善意 → 提供支持，不替代成长

经验可以指导行动，但不能免于被现实审判。
主体性不是拒绝帮助，而是不把最终判断、行动与责任永久外包。

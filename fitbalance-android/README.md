# 动衡 FitBalance v1.1.0

独立 Android 健身与营养管理 App；共享业务层从代码结构上保持 Android + iOS 兼容，当前仅发布 Android。

## v1.1.0 新增

- 固定 App UI 缩放：Text Zoom 100%，关闭手势缩放与网页式过度滚动反馈
- Android 原生步数桥继续可用
- 增加 iOS WKWebView / Core Motion 桥接兼容接口与 Swift scaffold
- 每日记录香烟支数
- 每日记录啤酒 ml + %vol
- 每日记录白酒 ml + %vol
- 自动换算纯酒精克数：体积 × 酒精度 × 0.789 g/ml
- 每日记录熬夜时长
- 首页“负 Buff”可视化与最近 7 日趋势
- “负 Buff”明确标记为个人行为趋势指标，不是临床死亡/心血管风险评分

## 已实现

- 每日蛋白质、碳水、脂肪、热量摄入
- 身高、体重、BMI、BMR/TDEE 与目标热量估算
- 糖尿病与痛风健康提示
- 16:8 / 14:10 / 12:12 饮食窗口
- 手机硬件步数传感器 + 手动步数兜底
- 走路、跑步、力量、骑行记录与 MET 热量估算
- 摄入 / 活动消耗 / 净摄入
- 胸、背、腿、肩、手臂、核心肌群恢复记录
- 体重趋势
- 拍照记录餐盘 + 本地选择/校正食物与份量后自动计算营养
- 主要数据默认保存在手机本地

## 双端发布策略

- 共享产品逻辑只维护一套
- Android 先发布和验证用户需求
- iOS 代码接口从第一天兼容
- 有真实 iOS 用户需求后再办理 Apple Developer Program、签名与 TestFlight / App Store 分发
- 不因为暂时不发布 iOS 而重写产品逻辑

## 健康提示

烟草使用不设“安全支数”；酒精记录为暴露量，不将任何非零饮酒量标为“安全”。负 Buff 只用于自己的行为趋势对比，不应解释成临床风险概率。

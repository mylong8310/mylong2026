# 动衡 FitBalance v1.2.0

共享业务层按 Android + iOS 双端兼容设计，当前继续优先发布 Android。

## v1.2.0

- 新增高血压、冠心病/其他心脏病、既往心肌梗死、既往脑卒中/TIA 模式
- 第一次启动显示可跳过的基础健康问卷
- 支持两位紧急联系人：姓名、关系、手机号
- 心脑血管高风险模式开启后，首页显示 ICE 紧急联系卡
- 一键进入系统电话呼叫流程：
  - 中国大陆院前急救：120
  - 主要紧急联系人
  - 备用紧急联系人
- Android 使用系统 ACTION_DIAL，不索取 CALL_PHONE 权限
- iOS scaffold 使用 tel:// 交由系统电话界面确认
- 紧急联系人只保存在设备本地
- 加入 2025 AHA/ACC 急性冠脉综合征常见警讯提示
- 加入 American Stroke Association B.E.F.A.S.T. 卒中识别提示

## 为什么不直接后台静默拨号

普通第三方 App 不应绕过系统电话安全确认，尤其是急救号码。v1.2.0 的目标是“一次点击进入系统呼叫流程”，由 Android/iOS 的系统电话组件完成最终呼叫确认。

## 已有功能

- 蛋白质 / 碳水 / 脂肪 / 热量
- 体重、BMI、BMR/TDEE
- 糖尿病、痛风/高尿酸
- 16:8 / 14:10 / 12:12
- 步数、走路、跑步、力量、骑行
- 肌肉恢复
- 食物拍照记录
- 吸烟、白酒、啤酒、纯酒精克数、熬夜时长负 Buff
- Android/iOS 原生桥兼容

## 医疗边界

本应用不是急救分诊工具。新的持续胸痛、明显呼吸困难、意识改变，或疑似卒中症状，应直接呼叫当地急救服务，不等待 App 计算结果。

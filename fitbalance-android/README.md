# 动衡 FitBalance v1.0.0

独立 Android 健身与营养管理 App。

## 已实现

- 每日蛋白质、碳水、脂肪、热量摄入记录
- 身高、体重、BMI、BMR/TDEE 与目标热量估算
- 糖尿病模式：加强碳水分布、低血糖与禁食安全提醒
- 痛风模式：加强高嘌呤、酒精、高果糖、脱水和快速减重提醒
- 16:8 / 14:10 / 12:12 饮食窗口
- 手机硬件步数传感器 + 手动步数兜底
- 走路、跑步、力量、骑行运动记录与 MET 热量估算
- 摄入 / 活动消耗 / 净摄入
- 胸、背、腿、肩、手臂、核心肌群恢复记录
- 体重趋势
- 拍照记录餐盘 + 本地选择/校正食物与份量后自动计算营养
- 所有主要数据默认保存在手机本地

## 关于拍照营养识别

v1.0.0 不把 API 密钥写进 APK，也不会伪装成“纯离线图像识别”。
当前流程是：拍照 -> 选择/校正食物 -> 输入份量 -> 自动计算。

后续若需要真正 AI 图片识别，应通过独立安全后端调用视觉模型，再由用户确认识别结果与份量。

## 健康提示

本应用提供的是一般运动营养与生活方式估算，不替代医生、营养师或糖尿病/痛风治疗方案。

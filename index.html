X API Local MCP Development

This website describes a personal developer project for local X API testing with a self-hosted MCP server. The project is used to connect a local coding environment to X API credentials for development, learning, and read-only analysis workflows.

The application is intended for local use by the repository owner. It is not a public product, data broker, automation service, or resale service.

Intended use

  • Search recent public posts for development and testing.
  • Look up public user profile information by username.
  • Retrieve public trends where allowed by the X API plan.
  • Keep API credentials in local environment variables or secure secret storage.

Data and safety boundaries

  • No X API data is sold, redistributed, or provided to third parties.
  • No spam, abusive automation, unauthorized scraping, or surveillance use is intended.
  • No posting, liking, following, direct messaging, or account-write action is enabled by default.
  • Secrets, tokens, and authorization headers are not published in this repository or on this page.
